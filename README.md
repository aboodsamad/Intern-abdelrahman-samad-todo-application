Project Description
a task mangment applicaioton that built to manage tasks creted by user using react, vite, typescreipt. developed as the project 2 of the internship schedule.

Features

Edit task: change the task after creating it.
Delete tasK: remve task from the list.
Mark task as completed: toggle task to mark it as complete.
Filter completed task: show only the completed task.
presistance: keep the created task showed on the page even after reloading it.
